========================================
GitHub云编译APK超详细教程（不用装任何软件）
========================================

优点：不用装Docker/WSL，不用本地配置环境，用GitHub免费服务器帮你编译，点几下就行。

----------------
第一步：注册GitHub账号
----------------
1. 打开 https://github.com/ 点右上角Sign up注册一个账号（免费）
2. 注册完登录账号

----------------
第二步：新建仓库
----------------
1. 登录后点右上角的+号 → New repository
2. Repository name随便填，比如 xp-simulator
3. 选Public（公开）
4. 勾选 Add a README file
5. 点最下面的 Create repository

----------------
第三步：上传代码
----------------
1. 进入你刚建的仓库页面
2. 点 Add file → Upload files
3. 把windows_xp文件夹里的【所有文件和文件夹】（包括.github文件夹）直接拖到网页里
   注意：是拖里面的文件，不是拖整个windows_xp文件夹！要让main.py在仓库根目录
4. 拉到最下面点 Commit changes

----------------
第四步：开始编译
----------------
1. 点仓库上面的 Actions 标签
2. 左边选 Build Windows XP APK
3. 右边点 Run workflow ▶ 按钮，再点绿色的 Run workflow
4. 等30-60分钟，页面会显示编译进度（黄点=编译中，绿勾=成功，红叉=失败）
   编译过程不用开着网页，关了也行，编译完GitHub会发邮件通知你

----------------
第五步：下载APK
----------------
1. 编译成功后（绿勾），点进那个编译任务
2. 拉到最下面 Artifacts 那里，点 Windows-XP-Simulator.apk 下载
3. 下载完传到手机安装就可以了！

----------------
如果编译失败：
----------------
1. 点进失败的任务，看具体错误
2. 一般是网络问题，重新点Run workflow再编译一次就行
3. GitHub服务器是配置好的，比本地编译成功率高很多
