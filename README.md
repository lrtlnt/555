# Windows XP 模拟器 (Python Tkinter)

一个用Python Tkinter实现的Windows XP模拟器，1:1还原经典XP界面，支持运行外部程序。

## 功能特性

### 🖥️ 桌面环境
- 经典XP蓝色桌面背景
- 桌面图标（我的文档、我的电脑、网上邻居、回收站、IE）
- 右键菜单
- 图标选中效果

### 📋 任务栏
- 经典蓝色渐变开始按钮（带Windows四色徽标）
- 快速启动栏
- 窗口按钮管理（最小化/恢复/切换）
- 系统托盘（音量、网络、实时时钟）
- 开始菜单（用户头像、左右分栏、注销/关机）

### 🪟 窗口系统
- XP风格渐变蓝色标题栏（活动/非活动状态）
- 窗口拖动、最小化、最大化/还原、关闭
- 标题栏按钮悬停效果
- 窗口激活/非激活状态切换
- XP风格菜单栏

### 📱 内置应用程序
1. **记事本** - 完整的文本编辑功能，支持打开/保存文件、复制粘贴、自动换行等
2. **计算器** - 标准计算器，支持加减乘除、开方、百分比、倒数等
3. **画图** - 简单绘图程序，支持铅笔、刷子、橡皮、喷枪、调色板等
4. **我的电脑** - 资源管理器，浏览文件系统、驱动器、文件夹
5. **运行** - 运行对话框，支持内置命令和外部程序
6. **关于Windows** - 经典的关于对话框

### ⚡ 运行外部程序
- 通过"运行"对话框可以启动系统上的其他程序
- 支持Windows (`os.startfile`)、macOS (`open`)、Linux (`xdg-open`)
- 内置命令：notepad, calc, mspaint, cmd, explorer, winver

## 文件结构

```
windows_xp/
├── main.py              # 主程序入口
├── constants.py         # XP主题颜色和常量定义
├── widgets.py           # XP风格自定义控件（按钮、窗口、菜单）
├── desktop.py           # 桌面和桌面图标
├── taskbar.py           # 任务栏、开始菜单、系统托盘
└── apps/                # 内置应用程序
    ├── __init__.py
    ├── notepad.py       # 记事本
    ├── calculator.py    # 计算器
    ├── paint.py         # 画图
    ├── my_computer.py   # 我的电脑/资源管理器
    ├── run_dialog.py    # 运行对话框
    └── about.py         # 关于Windows
```

## 运行方法

### 环境要求
- Python 3.6+
- Tkinter（Python自带，无需额外安装）

### 启动命令
```bash
cd windows_xp
python main.py
```

### 快捷键
- `Ctrl+Esc` - 打开开始菜单
- `Alt+F4` - 关闭当前窗口

## 使用说明

1. **打开程序**：双击桌面图标，或点击开始菜单选择程序
2. **窗口操作**：拖动标题栏移动窗口，点击按钮最小化/最大化/关闭
3. **运行程序**：开始菜单 → 运行，输入程序名或浏览选择文件
4. **文件浏览**：打开"我的电脑"浏览本地文件系统，双击文本文件会用记事本打开

## 技术说明

- 纯Python实现，仅使用标准库Tkinter，无需安装第三方依赖
- 所有XP风格控件（按钮、菜单、标题栏）均使用Canvas手绘实现
- 渐变效果通过逐行绘制不同颜色线条模拟
- 窗口管理系统支持多窗口层级、激活状态、最小化恢复
